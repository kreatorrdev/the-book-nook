# Documentation

The Book Nook is a deployed portfolio demo. All maintained project documentation is in English.

- [Project README](../README.md): setup, features, commands, and live demo.
- [Case study](CASE_STUDY.md): experience, design decisions, architecture, evidence, and limits.
- [Portfolio copy](PORTFOLIO_COPY.md): ready-to-use project description and a walkthrough outline.
- [Quality report](QUALITY_REPORT.md): final checks, changes, measurements, and verification limits.
- [Functional specification](THE_BOOK_NOOK_FUNCTIONAL_SPEC.md): ownership, progress, editions, writing, reviews, and moderation.
- [Current Gothic art direction](GOTHIC_ART_DIRECTION.md) and [hero provenance](HERO_GAME_REALISM.md): imagery, type, interaction, and generation brief.
- [Vercel deployment](VERCEL_DEPLOYMENT.md): infrastructure, environment variables, release process, and production checks.
- [Implementation status](IMPLEMENTATION_STATUS.md): delivered scope and optional later work.
- [Content provenance](CONTENT_INVENTORY.md): catalog facts, original text/covers, fonts, icons, and generated images.
- [Roadmap v0.2](04_THE_BOOK_NOOK_BOOKS_ROADMAP.md), [roadmap review](ROADMAP_REVIEW.md), and [original design baseline](THE_BOOK_NOOK_DESIGN_SPEC.md): planning history. Where these differ from the delivered demo, the current status and Gothic art direction take precedence.

The private repository contains source, original assets, screenshots, and these documents. Local credentials, the local reader database, runtime caches, and tool-specific state are excluded.
